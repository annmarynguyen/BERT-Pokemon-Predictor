# Pokémon Recommendation System Using BERT

**Originally completed: 2022**
**Repository updated: 2026**

## Overview

This project implements a BERT-based recomendation system that matches user personality descriptions to starter Pokémon using semantic similarity between BERT generated vectors.

## Dataset

A custom dataset was created with 31 starter Pokémon and short behavioral descriptions collected from Pokémon community resources.

## Methods

* BERT Embeddings
* Natural Language Processing (NLP)
* Vector Similarity (Dot Product)
* Random Forest Classification
* Nearest Neighbor Classification

## Results

* Generated BERT embeddings for Pokémon behavior descriptions
* Matched user personality descriptions to starter Pokémon
* Produced Pokémon recommendations based on semantic similarity
* Observed that Eevee was recommended more than expected, indicating limitations in the dataset and matching approach

## Key Takeaways

This project provided hands on experience with BERT and applying natural language processing and machine learning concepts to a recomendation system. It also highlighted how data quality and feature engineering can influence the effectiveness of recommendation systems.
